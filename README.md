# GitHub Sample Project

Dự án mẫu thực hành tạo repository, quản lý mã nguồn và thực hiện commit trên GitHub.

## Thông tin dự án
- **Mục tiêu:** Làm quen với quy trình tạo repository, chỉnh sửa file và lưu lịch sử thay đổi (commit) trên GitHub.
- **Tác giả:** Phạm Văn Nam
- **Trạng thái:** Đang thực hành cơ bản

## Cấu trúc thư mục
- `README.md`: Mô tả tổng quan về dự án.
- `index.html`: Trang web mẫu cơ bản.
